# OverTheWire Bandit: Linux Command Line Practice

## Goal
Get comfortable on the Linux command line by working through Bandit, a wargame where each level teaches a skill needed to find the password for the next one.

## Rules I followed
- No passwords or full solutions published, since OverTheWire asks players not to spoil it.
- Notes describe the concept and the commands in general terms, in my own words.

## Progress

| Levels | Main skills | Status |
|---|---|---|
| 0 to 4 | SSH, reading files, hidden files, special filenames | In progress |
| 5 to 9 | find, file types, sorting and filtering text | Not started |
| 10 to 14 | Encoding, decoding, keys, ports | Not started |
| 15 to 20 | TLS connections, nc, scanning, cron-style tasks | Not started |
| 21+ | Later pass | Not started |
